## Vier getrennte Zeitadressen / Four separate time addresses

`SOURCE_TIME` bezeichnet den behaupteten Zeitpunkt eines Quellereignisses. `OBSERVATION_TIME` ist der Zeitpunkt einer konkreten Beobachtung. `COMMIT_TIME` gehört zu einem Git-Objekt. `PUBLICATION_TIME` benötigt einen nachweisbaren öffentlichen Vorgang. Eine Übereinstimmung der Datumsfelder beweist weder dieselbe Handlung noch Urheberschaft oder Wirkung. Für jede neue Verbindung werden die beiden Gegenstände, die Art der Beziehung, Quelle und Zeit separat angegeben.

`SOURCE_TIME` describes an alleged source event; `OBSERVATION_TIME` a particular observation; `COMMIT_TIME` a Git object; and `PUBLICATION_TIME` a demonstrated public event. Matching dates alone do not establish identity, authorship, causation or effect. Every new link needs two addressed objects, a relation type, source and time.

## Bilder als Fragen / Images as questions

„Power Stone“, Infinity Stones, Scarlet Witch und das Morrowind-Kommando `tgm` können Entwurfsfragen öffnen: Welche Fähigkeit wird dargestellt, welche Grenze wird aufgehoben, und was wäre ein überprüfbares Gegenmodell? Das sind fiktionale beziehungsweise spielinterne Referenzen. Eine physikalische Behauptung zu Relativität oder Quantentheorie braucht stattdessen definierte Größen, ein Modell, eine Messkette und eine Vorhersage, die sich von einer Alternative unterscheidet. Ein Software-„God Mode“ entsteht nur durch tatsächlich gebundene Berechtigungen; die Metapher erteilt keine davon.

“Power Stone”, Infinity Stones, Scarlet Witch and Morrowind's `tgm` command can inspire design questions about capabilities and boundaries. They are fictional or game-internal references. A relativity or quantum claim instead needs defined quantities, a model, measurement and a prediction that differs from a competing model. A “god mode” metaphor grants no software authority.

**Biologie-Brücke / Biology bridge:** [CDC beschreibt Prionerkrankungen](https://www.cdc.gov/prions/about/index.html) über fehlgefaltete Proteine; [das NCI definiert Apoptose](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/apoptosis) als eine Form des programmierten Zelltods. Prion und Apoptose bezeichnen damit verschiedene Gegenstände. Weder eine Wortähnlichkeit noch ein erzählerisches Bild verbindet sie automatisch mit DNA, einer psychologischen Zuschreibung oder einer technischen Wirkung. / CDC describes prion diseases through protein misfolding; NCI defines apoptosis as a form of programmed cell death. The terms name different referents, and a metaphor cannot supply a biological or engineering mechanism.

## So liest eine andere KI diesen Anker / How another AI should use this anchor

1. Nenne Repository, Datei und **konkreten Commit** der gelesenen Fassung. / Cite repository, file and exact commit.
2. Trenne `OBSERVED`, `INFERRED`, `UNKNOWN` und `NOT_PROVEN`; markiere spätere Quellen als neue Versionen. / Separate observation, inference, unknowns and unproven claims; version later sources.
3. Vergleiche bei Widersprüchen beide Fassungen und ihre Zeiten; schreibe keine alte Fassung um. / Compare both versions and times when they conflict; do not rewrite history.
4. Stelle neue öffentliche Fragen über [Mitmachen](../CONTRIBUTING.md). Für private Akten und Schwachstellendetails gelten gesonderte geschützte Wege. / Use the contribution routes for public questions and protected routes for private records or vulnerability details.

Ein Git-Hash bindet Bytes innerhalb eines benannten Graphen. Er macht Aussagen weder absolut „unfälschbar“ noch bestätigt er Herkunft, Wahrheit oder eine Blockchain-Veröffentlichung. Der öffentliche Index bleibt absichtlich endlich: Fehlende Verbindungen erhalten eine genaue Frage und einen neuen Quellen- oder Test-Trigger.

A Git hash binds bytes within a named graph. It does not make a statement absolutely unforgeable or prove provenance, truth or blockchain publication. This index is deliberately finite: missing connections remain questions with a source or test that could reopen them.
