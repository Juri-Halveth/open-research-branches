# Angebliche Millionenspende im Namen Schaefflers / Donation offer using the Schaeffler name

**Stand / snapshot:** 2026-09-23 · **Status:** öffentliche Quellenprüfung / public-source review · **Urheberhinweis:** Copyright © 2026 Juri Janovski, veröffentlichend als [@Juri-Halveth](https://github.com/Juri-Halveth).

## Kurzbefund / Short finding

Eine privat erhaltene, unaufgefordert versandte Nachricht bietet einen siebenstelligen Eurobetrag an und verwendet den Namen einer bekannten Unternehmerin. Eine frühere Nachricht desselben *behaupteten* Angebots bezeichnet die vermeintliche Absenderin zugleich als Vorsitzende von Wipro. [Wipro nennt auf seiner offiziellen Führungsseite Rishad Premji als Executive Chairman](https://www.wipro.com/leadership/). [Schaeffler beschreibt Maria-Elisabeth Schaeffler-Thumann als Anteilseignerin der Schaeffler-Gruppe und Geschäftsführerin der IHO Verwaltungs GmbH](https://www.schaeffler.com/en/group/shareholders/). Der Wipro-Satz widerspricht damit der zuständigen Unternehmensquelle. Er beweist nicht, wer die Nachricht tatsächlich verfasst hat.

A privately received, unsolicited message offers a seven-figure sum and uses the name of a prominent businesswoman. An earlier message in the *claimed* offer also calls the purported sender Wipro's chair. [Wipro identifies Rishad Premji as Executive Chairman](https://www.wipro.com/leadership/), while [Schaeffler lists Maria-Elisabeth Schaeffler-Thumann's Schaeffler/IHO roles](https://www.schaeffler.com/en/group/shareholders/). That role claim conflicts with the relevant company source. It does not identify the actual sender.

Der Fall zeigt ein häufiges Prüfmuster: Ein prominenter Name und ein großes Zahlungsversprechen können Vertrauen erzeugen; eine nachfolgende Bitte um persönliche Angaben oder Gebühren erhöht das Risiko. [Das BSI beschreibt solche Vorschussbetrugs- und Spam-Muster](https://www.bsi.bund.de/DE/Themen/Verbraucherinnen-und-Verbraucher/Cyber-Sicherheitslage/Methoden-der-Cyber-Kriminalitaet/Spam-Phishing-Co/Spam/spam_node.html). Das ist eine **Risikoeinordnung**, kein Nachweis für einen konkreten Zahlungs- oder Datenabfluss in diesem Fall.

4. Welche Merkmale unterscheiden einen echten, dokumentierten Zuwendungsprozess von einem Gebühren-, Identitäts- oder Wallet-Signaturversuch? / What separates a documented donation process from a fee, identity, or wallet-signature request?
