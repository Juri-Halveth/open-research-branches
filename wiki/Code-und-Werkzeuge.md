## Was ein erfolgreicher Test bedeutet

Ein Test zeigt, dass die geprüfte Version mit den angegebenen Eingaben ein erwartetes Ergebnis erzeugt. Beim Dialogautomaten ist das eine Zustandsfolge; beim Pixelvergleich eine Differenz innerhalb einer definierten Region. Welche weitergehende Aussage sich daraus ergibt, hängt vom Modell und seiner Verbindung zur Anwendung ab.

Das [Glossar](Glossar.md) erklärt die verwendeten Statusbegriffe. Für die Nutzung der Dateien gilt die [Pfadlizenzkarte](https://github.com/Juri-Halveth/open-research-branches/blob/main/LICENSES.md).

## Gemeinsam weiterbauen

Ein hilfreicher Beitrag nennt das Werkzeug, die Eingabe, das erwartete Ergebnis und die tatsächlich beobachtete Ausgabe. Ein kleines Gegenbeispiel lässt sich oft besser nachvollziehen als eine sehr große Sammlung.
