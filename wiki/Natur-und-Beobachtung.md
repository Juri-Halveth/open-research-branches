# 🌱 Natur & Beobachtung

[Start](Home.md) · [Alle Projekte](Projekte.md) · [Licht & Energie](Licht-Wasser-und-Energie.md)

Eine Beobachtung ist ein wertvoller Anfang. Damit andere sie nachvollziehen können, brauchen sie den Gegenstand, die Bedingungen, den Zeitpunkt und die verwendete Methode. Dieser Raum bündelt die dazu veröffentlichten Protokolle.

## Ein gemeinsames Muster

| Feld | Beispiel für die Dokumentation |
| --- | --- |
| Gegenstand | Welche Probe, Pflanze oder synthetische Bildregion wird betrachtet? |
| Zeitpunkt | Wann entstand die Beobachtung, wann wurde sie aufgeschrieben? |
| Bedingungen | Was war an Beleuchtung, Temperatur, Umgebung oder Verarbeitung gebunden? |
| Methode | Welches Instrument oder Verfahren wurde in welcher Version verwendet? |
| Ergebnis | Welche konkrete Größe oder sichtbare Änderung wurde erfasst? |
| Interpretation | Welche Erklärung wird vorgeschlagen und welche Alternative bleibt offen? |

Diese Übersicht ist eine Lesehilfe zu den vorhandenen Protokollen. Die projektspezifischen Felder stehen in deren Originaldateien.

## Offene Beiträge

1. Eine synthetische Beispielreihe mit vollständig ausgefüllten Bedingungen ergänzen.
2. Zwei Auswertungen derselben öffentlichen Referenzdaten vergleichen.
3. Eine verständlichere Erklärung für Unsicherheit oder fehlende Beobachtungsintervalle schreiben.

Ein Protokoll macht Aufzeichnungen vergleichbarer. Ein biologischer Mechanismus oder ein medizinischer Nutzen benötigt darüber hinaus einen passenden Untersuchungsaufbau. Weitere noch nicht als Projekt veröffentlichte Natur- und Gesundheitsthemen sind im [Kandidaten-Ledger](https://github.com/Juri-Halveth/open-research-branches/blob/main/catalog/CANDIDATE_TOPICS.md) registriert.
