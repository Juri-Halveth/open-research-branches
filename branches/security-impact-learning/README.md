# Security Impact Learning · A failed inference, retained openly

**Status: public learning derivative and synthetic model.**

We measured an accessible configuration surface repeatedly and then described
its potential reconnaissance value too strongly. Readability, stable hashes
and a denied neighboring API did not establish the claimed policy violation.
That failed inference remains visible here, along with the missing evidence.

This is newly written, generalized learning material. Private case originals,
target identifiers, portal conversations, report IDs and live reproduction
scripts are not part of this branch. Historical outcomes described in private
summaries have not been independently reverified by this publication.

## Run the local example

```sh
node branches/security-impact-learning/demo.mjs
node --test branches/security-impact-learning/impact-model.test.mjs
```

The example evaluates declared synthetic facts. It has no network, credentials,
target selection, scanners, payloads, persistence or submission functions.
Its route is a model decision awaiting review, never an exploitation or
publication authorization.

## The corrected separation

| Axis | What it answers |
| --- | --- |
| Observation | What was returned or changed in the bound source? |
| Expected policy | Should this caller have this access? |
| Effect | Which protected property was actually affected? |
| Source / local / product binding | Where was the result established? |
| Severity | How serious is the demonstrated impact in that scope? |
| Program decision | What did the particular program decide? |
| Publication | Which exact derivative may be shared? |

Unknown evidence remains unknown. A public bootstrap can be intended and still
deserve field minimization. A protected read can have confidentiality impact
without persistence. A local counterexample can justify hardening without
claiming a live production failure.
