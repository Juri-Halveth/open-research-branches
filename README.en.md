**Concise project guide · EN / RU**

A source-linked collection of research branches, reports, software models and reproducible examples. It connects software, nature observation, language, media and social questions through a topic wiki and project catalogue.

Reports distinguish observations, interpretations, hypotheses and pending external steps. A local model, source hash or drafted complaint is not by itself an accepted vulnerability, delivered submission or payment. Historical permissions and new HALVETH contributions retain their versioned rights; private work certificates document artifacts rather than institutional personal qualifications.

This manually edited guide summarizes the audited source. The original technical documentation remains the reference for commands, build requirements, exact versions and detailed evidence.
