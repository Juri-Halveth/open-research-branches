# Security Policy

## Unterstützter Stand

Nur der aktuelle Stand des Standardbranches wird gepflegt. Die Beispiele sind
lokal, synthetisch und nicht für produktive Identitäts-, Sicherheits- oder
Gesundheitsentscheidungen bestimmt.

## Private Meldung

Bitte verwende auf GitHub die Funktion **Report a vulnerability** im Bereich
Security Advisories dieses Repositorys. Teile dort nur die zum Nachvollziehen
nötigen Informationen und keine fremden Zugangsdaten oder personenbezogenen
Daten.

Öffentliche Issues eignen sich für nicht-sicherheitskritische Fehler,
Dokumentation und Forschungsfragen.
